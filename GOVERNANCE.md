# Governance

The maintainer owns source review, release acceptance and private reporting. Contributors can propose changes through public issues and pull requests. CI and automated review assist the maintainer; they are not independent humans or backup maintainers.

The maintainer confirms familiarity with secure design principles and common Python/network application vulnerabilities. As of 2026-10-16 there were no bug reports, enhancement requests or vulnerability reports outside GitHub in the preceding twelve months.

There is currently no backup person or established mechanism that can regain repository, CI and release access within one week if the maintainer is unavailable. OpenSSF Silver access continuity and bus-factor requirements remain unmet. Do not imply that an automated bot solves succession. Establish delegated access and an agreed recovery process before changing these answers.
